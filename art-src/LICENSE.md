# Происхождение арта

Арт создан для этого проекта с помощью встроенного инструмента генерации изображений OpenAI (ChatGPT ImageGen); подготовку размеров, прозрачного окна рамки, подложки и превью выполнил Codex с помощью Pillow. Запросы описывали оригинальные изображения без персонажей, логотипов и копирования существующих игр или брендов; исходные сторонние символы проекта в готовый комплект не включены.

Согласно [условиям OpenAI](https://openai.com/policies/row-terms-of-use/), пользователь владеет результатом по отношению к OpenAI в пределах применимого права, что допускает публичное и коммерческое использование при соблюдении условий. Генерация не гарантирует уникальности: OpenAI указывает, что другие пользователи могут получить похожий результат.

Название Dragon Lanterns является рабочим; проверка товарных знаков не проводилась.
